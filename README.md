# Сайт-презентація "Gabinet Masażu Tina"

Готовий односторінковий сайт: `index.html` (все в одному файлі — HTML+CSS+JS, нічого встановлювати не треба). Є перемикач мови PL/UA у верхньому правому куті.

Зміст взято з публічної сторінки бронювання Booksy (адреса, графік, послуги, ціни, фото). Instagram не вдалось прочитати автоматично (Instagram блокує ботів через robots.txt), тому фото використані з Booksy — за бажання їх легко замінити на власні (див. нижче).

## Варіант 1: Netlify (найпростіше, без реєстрації для першого запуску)

1. Відкрийте https://app.netlify.com/drop у браузері.
2. Перетягніть папку `tina-site` (або сам файл `index.html`) у вікно браузера.
3. Через кілька секунд Netlify видасть посилання виду `https://random-name-123.netlify.app` — сайт вже онлайн і безкоштовний.
4. Щоб посилання не зникло і можна було оновлювати сайт пізніше — створіть безкоштовний акаунт на netlify.com (кнопка "Claim this site" з'явиться одразу після завантаження).
5. У налаштуваннях сайту (Site settings → Domain management) можна змінити випадкову назву на щось на кшталт `tina-masaz.netlify.app`, а пізніше — підключити власний домен (наприклад, tina-masaz.pl), якщо він з'явиться.

## Варіант 2: GitHub Pages (якщо вже є або плануєте акаунт GitHub)

1. Створіть безкоштовний акаунт на github.com (якщо ще немає).
2. Створіть новий репозиторій, наприклад `tina-masaz-site` (публічний).
3. Завантажте туди файл `index.html` (кнопка "Add file → Upload files").
4. Перейдіть у Settings → Pages, у розділі "Source" оберіть гілку `main` і папку `/root`, натисніть Save.
5. Через 1–2 хвилини сайт буде доступний за адресою `https://<ваш-логін>.github.io/tina-masaz-site/`.

## Як замінити фото на власні

У файлі `index.html` фото підключені прямими посиланнями на CDN Booksy (рядки з `<img src="https://d375139ucebi94.cloudfront.net/...">`). Щоб поставити свої фото:

1. Складіть фото у папку `images/` поруч з `index.html` (наприклад `images/hero.jpg`, `images/photo1.jpg`).
2. У тексті `index.html` замініть відповідний `src="https://..."` на `src="images/hero.jpg"` (і так для кожного фото).
3. Перезавантажте оновлений файл на Netlify/GitHub тим самим способом.
